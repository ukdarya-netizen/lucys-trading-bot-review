2. БЕЗОПАСНЫЙ ПРОФИЛЬ НОВОГО ПРОЕКТА
В новом проекте, и в development, и в настройках будущей публикации:

Не нажимать в интерфейсе включение торговли.

Почему EXECUTOR_V2=1: при значении 0/отсутствии переменной API запускает
старый startBotWorker и в production может дополнительно запустить worker.
Поэтому EXECUTOR_V2=0 НЕ является универсальной безопасной паузой.
При указанном профиле loadAccounts нового executor должен вернуть 0 счетов.
Контрольная строка старта: executor: started, accounts: none.
Безопасность здесь обеспечена сочетанием всех условий, а не одним флагом:
пустая отдельная БД, отсутствие биржевых/Telegram ключей, оба аккаунтных флага
выключены, отсутствие внешнего потока сигналов.
