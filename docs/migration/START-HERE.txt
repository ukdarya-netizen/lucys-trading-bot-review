ЗАДАНИЕ ДЛЯ AGENT В НОВОМ ПРОЕКТЕ

Это импорт существующего торгового бота, НЕ новое приложение.
Прочитай MIGRATION-GUIDE.txt из корня архива.
Сохрани код и текущие торговые правила без самостоятельных изменений.
Сначала только установка, сборка и тестовая публикация БЕЗ торговли.
Не подключай старую production-БД. Используй отдельную пустую тестовую БД.
Проверь EXECUTOR_V2=1, EXECUTOR_OWNER_VST=0, EXECUTOR_SUBSCRIBERS=0,
SUBSCRIBER_BOT_IN_DEV=0 в development и publication. Не добавляй биржевые
и Telegram токены и не направляй сюда сигналы.
Не считай EXECUTOR_V2=0 безопасной паузой: он включает старый runtime.
Не запускай db push/force или post-merge.sh без отдельного preview и разрешения.
Не выполняй диагностические скрипты ордеров/контрольные сделки.
Не включай GitHub autosync и не перезаписывай репозиторий.
Проверь регистрацию API и web артефактов в новом проекте штатными средствами,
не переноси старые artifact ID как подтверждение регистрации.
Не меняй Clerk tenant/авторизацию и не обещай перенос пользователей без проверки.
После проверок пришли фактические build/test результаты и остановись перед
переносом данных, изменением секретов, подключением сигналов и активацией торговли.
